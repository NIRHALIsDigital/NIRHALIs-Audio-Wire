# NIRHALIs Audio & Wire

Shopify theme source and product catalog snapshot for [NIRHALIs Audio & Wire](https://audioandwire.nirhalisdevelops.com).

The root theme directories reflect the live Shopify theme, **NAW — Cart Trust & Payment Confirmation**, as captured on 20 November 2026. Theme media referenced through Shopify stays hosted there.

The [product catalog snapshot](catalog/products.json) records active and draft products, variant prices, and whether Shopify reported positive inventory. Draft listings include basic product and variant information. Internal checkout verification records are excluded. Shopify is the source of truth for current prices, inventory, and publication status. The JSON is a reference snapshot.
